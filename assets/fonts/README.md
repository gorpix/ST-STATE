# Optional local phone fonts

ST-STATE does not redistribute proprietary phone fonts. For the closest iPhone rendering, place legitimately obtained copies of these files here:

- `SFPRODISPLAYREGULAR.OTF`
- `SFPRODISPLAYMEDIUM.OTF`
- `SFPRODISPLAYBOLD.OTF`

The renderer loads them locally and falls back to the host system font stack when they are absent.
